# Handoff: Standard 1.4 proportionate security and evidence

## Task

Publish a compact Agent Handoff rule that prevents security and evidence work from blocking acceptance or expanding scope unless a current-scope risk is verified as High or Critical, without weakening the existing security baseline.

## What changed

- Added the normative security-and-evidence threshold to Standard 1.4.
- Allowed blocking or scope expansion only for a verified High or Critical current-scope risk supported by reproducible evidence or a directly applicable authoritative source.
- Limited a suspected High or Critical risk to a short, time-boxed investigation until confirmed.
- Kept Low, Medium, unrated, and unverified risks non-blocking.
- Preserved exact acceptance criteria and verified mandatory requirements as independent blockers only when cited.
- Prioritized the smallest useful end-to-end scenario for MVPs, prototypes, and runtime spikes.
- Kept the 10–15% security-and-evidence share as a non-binding planning heuristic that may be substantially exceeded only for a verified High or Critical risk or an exactly cited mandatory requirement.
- Synchronized the agent guide, handoff and reporting protocols, Pull Request checklist, public adoption prompts, release metadata, project state, decisions, and public pages.
- Added one structural checker requirement for the new PR checklist item.
