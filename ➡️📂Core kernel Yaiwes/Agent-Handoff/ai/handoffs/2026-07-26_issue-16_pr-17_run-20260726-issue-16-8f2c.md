# Handoff: Standard 1.5 outcome-oriented execution

## Primary outcome

Prepare a reviewable Agent Handoff Standard 1.5 release candidate that prevents supporting work from becoming an independent delivery or approval loop while preserving explicit safety and permission boundaries.

## Smallest acceptance proof

The standard, Work Claim, Task Report, Handoff, GitHub workflow, Pull Request checklist, and structural checker agree on the primary-outcome, execution-envelope, post-fix verification, stage and handoff, approval-boundary, and `progress-stalled` rules.

## Reason for the change

Standard 1.4 constrained disproportionate security and evidence work, but the general workflow still allowed a repaired supporting layer to qualify as a stable stage. A smoke wrapper, test harness, CI layer, evidence collector, release helper, or incidental refactoring failure could therefore create its own report, handoff, owner approval gate, and verification cycle without advancing the Issue's primary outcome.

Standard 1.5 closes this process gap for all kinds of work, not only security work.

## What changed

- Added the normative outcome-oriented execution and bounded supporting-work rule.
- Required `Primary outcome`, `Smallest acceptance proof`, and `Execution envelope` in meaningful Work Claims.
- Defined outcome progress and supporting work.
- Distinguished an unchanged retry from bounded verification after an evidence-based fix.
- Kept localized, reversible, in-scope supporting fixes and verification inside the original authorization.
- Defined the exact boundaries that require a new owner decision.
- Replaced auxiliary-layer stability with outcome-based stage and handoff boundaries.
- Added `progress-stalled` recovery after two consecutive supporting-only updates without outcome progress.
- Updated task reporting, refactoring guidance, the Pull Request checklist, and structural checks.
- Synchronized public documentation, release notes, citation metadata, changelog, project state, decisions, and promotion checklists for Standard 1.5.
