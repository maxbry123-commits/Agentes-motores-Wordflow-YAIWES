# Resources

Curated external resources for building AI agents — tools, courses,
communities, and reference material that complement (but aren't a
replacement for) the pages in this repository.

## How to Use This Page

This is intentionally a lighter-touch page than the rest of the repository:
external tools and communities change fast, so treat these as a starting
point for your own research rather than an endorsement of "the best" option
in each category. Always check current documentation/reviews before
committing to a specific tool.

## Categories of Tooling (Vendor-Neutral)

| Category | What to look for |
|---|---|
| Agent frameworks | Support for the patterns in [`13-agent-patterns/`](../13-agent-patterns/README.md), active maintenance, good tool-calling ergonomics |
| Vector databases | Fit for your scale (see [`10-rag/vector-databases.md`](../10-rag/vector-databases.md)), metadata filtering support, hosting options that fit your infra |
| Observability platforms | Tracing support for multi-step/multi-agent flows (see [`14-observability/`](../14-observability/README.md)) |
| Evaluation tooling | LLM-as-judge support, custom benchmark authoring, regression test tracking (see [`15-evaluation/`](../15-evaluation/README.md)) |
| MCP server directories | Community-maintained lists of available MCP servers (see [`11-mcp/`](../11-mcp/README.md)) |

## Learning Resources

- Official documentation from each model provider (see
  [`17-models/README.md`](../17-models/README.md)) — always the most
  current source for provider-specific capabilities
- The original research papers cited throughout this repository — see
  [`papers/README.md`](../papers/README.md) — for first-hand technique
  explanations
- University-level NLP/ML courses covering transformer architectures, for
  foundational understanding beneath agent-specific techniques

## Communities

- This repository's own [GitHub Discussions](../.github/DISCUSSIONS.md)
- Model provider developer communities/forums (check each provider's
  official channels)
- Open-source agent framework communities (check each framework's own
  repository for community links)

## Newsletters and Ongoing Coverage

Given how fast this field moves, following active researchers, provider
blogs, and community-curated newsletters is more reliable than any static
list in this repository — check provider blogs and well-known AI-focused
newsletters directly rather than relying on names baked into this file,
which would go stale.

## Contributing to This Page

Have a resource that's been genuinely useful? Open a PR following
[`CONTRIBUTING.md`](../CONTRIBUTING.md). Prefer resources that are:

- Actively maintained (check last-update dates)
- Vendor-neutral where the category calls for it, or clearly labeled as
  vendor-specific
- Genuinely complementary to (not duplicative of) content already in this
  repository
