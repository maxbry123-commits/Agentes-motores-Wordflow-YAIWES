- how the project moved from four domain problems to a common research-control language;
- observations that changed engineering or scientific direction;

## What it excludes

- raw competition logs and exact prompts;
- official inputs, outputs, checkpoints, and submission artifacts;
- internal endpoints, infrastructure, credentials, image identities, and absolute paths;
- restricted reviewer and defense materials;
- third-party source or assets without publication rights.

The reconstructed traces under [`evidence/`](../evidence/README.md) are explicitly labeled and should be read alongside this notebook.
