# Research agenda

This agenda separates completed work from experiments that still need evidence.

## Current baseline

- Task contracts, evidence events, verifier gates, rollback, and atomic delivery.
- Synthetic end-to-end example and tests.
- Four evidence-bounded case studies.
- Reconstructed traces clearly separated from raw logs.
- File manifest, publication audit, license review, and CI verification.

## Next — controlled context and review

- Explicit token/time budgets for context selection.
- Typed summary records with source pointers and uncertainty.
- Independent reviewer interface with deterministic checks as source of truth.
- Fault-injection tests for tool timeout, malformed output, stale state, and rollback.

## Next — memory experiments

- Short-term episodic memory with expiry and provenance.
- Cross-run research memory containing only verified conclusions.
- Socratic questions stored as unresolved hypotheses rather than facts.
- Tests for stale-memory contamination, workload growth, and deletion.

## Next — public scientific adapters

- License-safe adapters for one or more open scientific benchmarks.
- Same-budget comparisons against deterministic workflow and single-agent baselines.
- Repeated-run reporting with variance, failure rate, cost, and wall time.

## Explicit non-goals

- Claiming that more agents necessarily improve scientific quality.
- Releasing competition data, original submissions, private services, or restricted weights.
- Reproducing historical platform scores without equivalent data, versions, hardware, and evidence.
