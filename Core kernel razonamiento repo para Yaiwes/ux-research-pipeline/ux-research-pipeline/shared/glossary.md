# Glossary

The team's glossary of terms.

## Methodology — qualitative

| Term | Meaning |
|---|---|
| in-depth interview | A semi-structured interview, usually 60–90 min, conducted one-on-one. |
| interview guide | A list of blocks and questions with timing. |
| screener | A questionnaire for selecting respondents. |
| debrief | A team discussion of an interview immediately afterward, before analysis. |
| saturation | The state in which new interviews no longer add materially new information. |
| triangulation | Comparing data from different sources (methods, respondents, points in time). |
| disconfirming case | Data that contradicts an emerging theory or model. |
| inscription | A mismatch between what a respondent says and what their behavior shows. |
| flat coding | Coding that stays close to the respondent's words, without a hierarchy. |
| axial coding | Grouping codes into categories and axes. |
| paradigm model | A grounded-theory structure: conditions → context → actions → consequences. |
| in vivo coding | Codes phrased verbatim from the respondent's speech. |
| jobs-to-be-done (JTBD) | "What the product is hired to do" — a frame for user motivation. |
| customer journey map (CJM) | A map of the user's path through the product. |
| projective technique | An indirect question (metaphor, scenario) used to surface data that a direct question cannot. |

## Methodology — quantitative (for the boundary)

| Term | Meaning |
|---|---|
| quantitative | Metrics, surveys with N >> 30, statistical significance. |
| tracker | A recurring survey with a fixed design. |
| wave | A single run of a tracker. |

## Pipeline-specific

| Term | Meaning |
|---|---|
| RQ | research question |
| DoD | Definition of Done — the "closed" criterion. |
| codebook | The dictionary of all codes in a project. |
| Verbatim quote | A word-for-word quote with a timecode. |
| Saturation map | A map of how themes are closed across interviews. |
| Concerns | A summary of the agent's doubts in autonomous mode. |
| Handoff | The final document for the researcher in autonomous mode. |
