# Agent Skill Lab — resumo em português

O Agent Skill Lab é um projeto open-source e independente de plataformas para testar
skills de agentes de inteligência artificial.

O objetivo é ajudar criadores e utilizadores a compreender:

- se uma skill está corretamente estruturada;
- em que agentes poderá funcionar;
- que alterações serão necessárias para cada plataforma;
- que ficheiros, comandos, rede, credenciais e ferramentas poderá utilizar;
- se o comportamento observado corresponde ao objetivo declarado.

O projeto não pretende ser apenas mais um scanner de malware. A segurança será uma
parte importante, mas o foco diferenciador será a compatibilidade, transparência de
permissões, qualidade e testes reproduzíveis.

## Estado atual

O projeto encontra-se na fase de investigação e especificação. Ainda não existe uma
versão executável.

A primeira versão deverá analisar uma pasta local sem executar o seu conteúdo, validar
o formato, produzir um manifesto de capacidades e gerar relatórios em Markdown e JSON.

## Público

O projeto é internacional. A documentação e o código principais serão escritos em
inglês, mantendo-se resumos e materiais em português sempre que for útil.
