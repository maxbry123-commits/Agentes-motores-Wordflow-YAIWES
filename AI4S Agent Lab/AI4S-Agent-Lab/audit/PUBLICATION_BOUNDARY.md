# Publication boundary

## Purpose

AI4S Agent Lab is a personal research project created, directed, reviewed, and maintained by Wanrun Cong with disclosed programming-agent assistance. Its project identity and publication responsibility belong to the author alone. The code, tests, synthetic examples, reconstructed evidence, and documentation published here were created for this project.

## Public categories

| Category | Rule |
|---|---|
| Personal implementation | Original, task-agnostic code created under Wanrun Cong's direction, review, and publication responsibility; Apache-2.0 |
| Synthetic fixtures | Self-authored, small, and independent of official competition data |
| Public narrative | Written from author-reviewed factual summaries; no sensitive paths or operational detail |
| Reconstructed traces | Explicitly labeled `reconstructed: true` and `not_original_log: true` |
| Historical results | Reported with version and reproducibility boundaries |
| Third-party references | Link and attribution only unless a later manifest closes redistribution rights |

## Excluded categories

- Git history and large-file objects from historical competition work;
- original logs, prompts, outputs, predictions, and checkpoints;
- submission archives, review packages, images, digests, and private base layers;
- official problem attachments, hidden inputs, authenticated downloads, and evaluation data;
- credentials, private endpoints, infrastructure identities, and user-specific paths;
- internal defense/attack notes and competitor analysis;
- source, weights, templates, stocks, or datasets with incomplete third-party provenance;
- the task4 prebuilt training tools ruled out of bounds;
- claims that future plans or reconstructed traces are completed historical results.

## Historical evidence boundary

Historical scores, rulings, and version observations are included only as contextual records from the author's participation. Original logs, official data, submission artifacts, scoring environments, and other restricted evidence remain outside this repository. The absence of those carriers is stated wherever it limits a claim.

## License boundary

Apache-2.0 applies only to original files in this personal repository. It does not grant rights to:

- historical competition source and artifacts outside this repository;
- competition-organizer material;
- third-party scientific systems;
- model weights, datasets, or online services;
- trademarks or logos.

## Trace rule

A reconstructed trace is acceptable only when:

1. it contains both required reconstruction flags;
2. it states its evidence basis and claim limit;
3. it contains no sensitive original line or identifying path;
4. it does not add exact values absent from public-safe evidence;
5. it is never described as the original run log.
